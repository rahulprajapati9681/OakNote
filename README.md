# OakNote

OakNote is an offline-first productivity app built with Flutter that helps students manage their timetable, attendance, and daily tasks in one place.

The app is designed to be simple, fast, and reliable, with all data stored locally so it works even without an internet connection.

> **Current Status:** v1.0.0 (Google Play Closed Testing)

---

## Features

- Timetable and schedule management
- Attendance tracking with percentage calculation
- Daily task management
- Local notifications and reminders
- Performance analytics
- Offline-first architecture
- Fast and responsive UI

---

## Built With

- Flutter
- Dart
- Hive
- Provider
- Flutter Local Notifications

## About

OakNote started as a personal project to solve the problem of managing attendance and class schedules without relying on multiple apps. The focus was on creating a clean user experience while keeping the app lightweight and fully functional offline.

The project is actively being improved based on feedback from early testers.
